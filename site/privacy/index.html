01 Privacy

How Code Echo handles code

Effective 27 August 2026

Short version: Code Echo does not send selected code, reading history, pronunciations, or visual preferences to us. The extension works locally and has no analytics.

What the extension stores

Code Echo stores settings, your pronunciation dictionary, an optional license token, and up to ten recent selections in Chrome extension storage on your device. You can clear replay history from the popup. Chrome may sync settings only when you buy the Echo Pack and explicitly turn on “Sync settings.” That transfer is provided by your browser account, not by Code Echo.

Speech disclosure

The extension uses the Web Speech API. The voice is provided by your browser or operating system. Some installed voices work entirely on-device; other browser or operating-system configurations may send speech text to their voice provider. Check your browser and operating-system speech settings if local-only speech is important to you. Code Echo cannot see which provider your browser uses.

Website storage

The website stores your theme choice, and—if you purchase or restore the Echo Pack—your license token plus a verification result and timestamp in localStorage. Verification sends only the license token to the Sociobot billing API, at most once per day. The website has no advertising, behavioral analytics, pixels, or third-party runtime scripts.

Purchases

Checkout and license verification are handled by Sociobot, with Dodo as merchant of record. Their checkout collects the information needed to complete the purchase under their own policies. Code Echo never receives card details.

Network and deletion

Selected code is never included in a network request by Code Echo. Remove extension data by clearing history/preferences or uninstalling the extension. Remove website data through your browser’s site-data controls. Purchase records required by law remain with the merchant of record.

Contact

For privacy questions, email privacy@sociobot.in. We will update the effective date when this policy changes materially.
