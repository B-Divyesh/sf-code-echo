05 Privacy is the architecture

Your code is not our input.

Parsing, preferences, and ten-item replay history live in the extension. Code Echo has no analytics and no server for snippets. Web Speech uses a voice supplied by your browser or operating system; depending on those settings, that provider may process spoken text.
